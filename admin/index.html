ربط GitHub

يُستخدم لتفعيل/إيقاف الصيانة وقراءة معلومات المستودع. الرمز يُحفظ في متصفحك فقط ولا يُرسل لأي جهة عدا GitHub.

كيف أحصل على الرمز؟
  1. افتح صفحة إنشاء Fine-grained token
  2. الصلاحية: Only select repositories → i6naF/webgis
  3. Permissions → Contents → Read and write
  4. أنشئ الرمز وانسخه والصقه هنا

عدّاد الزوار (GoatCounter)

موقعك مربوط مسبقاً بحساب webgis-i6na. الإجمالي يُقرأ تلقائياً بدون أي إعداد. لعرض التفاصيل اليومية، أضف مفتاح API بالأسفل.

.goatcounter.com
كيف أحصل على مفتاح API؟
  1. ادخل على لوحة GoatCounter → API
  2. اضغط Add token وفعّل صلاحية Read statistics
  3. انسخ المفتاح والصقه هنا
