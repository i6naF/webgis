ربط وربط مستودع GitHub
REPOSITORY SYNC

يُسخدم هذا التكوين للحصول على ترخيص التعديل الفوري لمحتوى الموقع الرئيسي (مثل نشر الصيانة أو الإعلانات). يُحفظ هذا الرمز بشكل مشفّر تماماً داخل متصفحك الحالي ولا يرسل لأي طرف خارجي.

طريقة استخراج الرمز (PAT Token) الخاصة بمستودعك على GitHub
  1. افتح صفحة المطورين على GitHub لإنشاء رمز جديد: Personal Access Tokens
  2. من الخيارات اختر: Only select repositories → i6naF/webgis
  3. من جدول التراخيص (Permissions) اختر: Contents → Read and write
  4. اضغط على زر (Generate Token) وانسخ الرمز الصادر والصقه في الحقل أعلاه.
ربط وربط إحصائيات GoatCounter
ANALYTICS ENGINE

يتم استخدام حساب GoatCounter المُعد مسبقاً للبوابة الجغرافية. لعرض التحليلات المتكاملة كالجداول التفصيلية والرسومات الموزعة، يرجى ملء الحقول بالأسفل.

.goatcounter.com
طريقة استخراج مفتاح وصول التحليلات (GoatCounter Read Token)
  1. ادخل لوحة تحليلات GoatCounter الخاصة بك وافتح صفحة التراخيص: GoatCounter API Settings
  2. اضغط على زر (Add Token) وقم بتفعيل خيار القراءة: Read statistics
  3. انسخ الرمز الصادر وضعه في حقل مفتاح التحليلات أعلاه للحفظ المباشر.
ربط مفتاح PageSpeed Insights (Google Cloud)
PERFORMANCE ENGINE

إجراء فحص سرعة وأداء الصفحة للزوار يعمل بدون حاجة لإضافة مفتاح، ولكن إضافة هذا المفتاح تزيد حصة الاستهلاك المسموحة لك من خوادم Google Cloud.

إعادة ضبط وتهيئة لوحة التحكم للمتصفح
DANGEROUS ZONE

الضغط على الزر أدناه سيقوم بمسح كافة الرموز المخزنة محلياً، وكلمة المرور الحالية، وإعدادات GoatCounter وإجبارك على إعادة إعداد لوحة التحكم من البداية.
