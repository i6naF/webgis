ربط GitHub

يُستخدم لنشر التغييرات (صيانة، إعلانات، أقسام) وقراءة معلومات المستودع. الرمز يُحفظ في متصفحك فقط.

كيف أحصل على الرمز؟
  1. افتح صفحة إنشاء Fine-grained token
  2. الصلاحية: Only select repositories → i6naF/webgis
  3. Permissions → Contents → Read and write
  4. أنشئ الرمز وانسخه والصقه هنا

عدّاد الزوار (GoatCounter)

موقعك مربوط مسبقاً بحساب webgis-i6na. الإجمالي يُقرأ تلقائياً. لعرض التفاصيل أضف مفتاح API.

.goatcounter.com
كيف أحصل على مفتاح API؟
  1. ادخل على لوحة GoatCounter → API
  2. اضغط Add token وفعّل Read statistics
  3. انسخ المفتاح والصقه هنا

مفتاح PageSpeed (اختياري)

قياس الأداء يعمل بدون مفتاح، لكن المفتاح يرفع حدّ الاستخدام. احصل عليه من Google Cloud (PageSpeed Insights API).
